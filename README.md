## Sobre o projeto

Interactable é um jogo educativo no estilo sandbox 2D,
desenvolvido com foco em acessibilidade, experimentação,
criatividade e estímulo cognitivo.

O projeto foi idealizado no contexto de uma atividade
acadêmica extensionista, tendo como público-alvo alunos
da APAE de Jaraguá do Sul.

O jogador possui liberdade para adicionar, movimentar
e combinar diferentes objetos dentro de uma arena,
descobrindo suas interações de maneira intuitiva.

O jogo não possui fases, pontuações ou objetivos
obrigatórios. A experiência é baseada na exploração
livre e na curiosidade do jogador.

## Funcionalidades

- Arena interativa em duas dimensões.
- 14 objetos com diferentes comportamentos.
- Interações físicas entre objetos.
- Sistema de combustão e extinção.
- Congelamento e derretimento.
- Atração magnética.
- Animações e efeitos de partículas.
- Pausa e continuação da simulação.
- Adição e movimentação de objetos durante a pausa.
- Remoção individual de objetos.
- Interface visual com ícones e sem dependência de leitura.
- Destaque visual dos objetos selecionados.

## Download e instalação

### Windows (64 bits)

1. Acesse a página de Releases deste repositório.
2. Selecione a versão mais recente disponível.
3. Localize a seção "Assets".
4. Baixe o arquivo:
   Interactable-v0.1.0-Windows-x64.zip
5. Clique com o botão direito sobre o arquivo baixado.
6. Selecione a opção "Extrair Tudo".
7. Abra a pasta extraída.
8. Execute o arquivo Interactable.exe.

Não é necessário instalar a Godot ou qualquer
ambiente de desenvolvimento para jogar.

O Interactable é um jogo portátil e não necessita
de um instalador.

### Requisitos

- Sistema operacional Windows de 64 bits.
- Mouse para interação com os objetos.
- Hardware compatível com o renderizador da Godot.

Os requisitos mínimos de hardware ainda estão
em fase de avaliação.

## Como jogar

| Controle | Ação |
|---|---|
| Selecionar um ícone | Escolher um objeto |
| Soltar o clique esquerdo na arena | Adicionar objeto |
| Clique esquerdo + arrastar | Movimentar objeto |
| Clique direito | Remover objeto |
| Botão com ícone de pausa | Pausar simulação |
| Botão com ícone de reprodução | Continuar simulação |
| Botão com ícone de lixeira | Limpar arena |

Durante a pausa, os objetos podem ser adicionados,
movimentados e removidos livremente.

Ao continuar a simulação, os objetos voltam a se
movimentar e interagir.

## Acessibilidade

O Interactable foi projetado para reduzir a dependência
de instruções escritas, utilizando elementos visuais,
ícones, animações e interações intuitivas.

Entre os recursos de acessibilidade estão:

- Interface baseada em imagens.
- Ícones grandes e identificáveis.
- Mecânicas simples.
- Ausência de limites de tempo.
- Liberdade de experimentação.
- Controle da simulação por meio da pausa.
- Feedback visual das interações.

## Tecnologias utilizadas

- Godot Engine 4.7.2
- GDScript
- Física 2D
- Sistema de partículas
- Animações por Tween
